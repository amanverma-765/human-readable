## Overview

Readers frequently observe that text generated by modern frontier language models is dense, exhausting, and unnatural. While early research focused on lexical mannerisms (such as the overuse of words like `delve`), recent empirical work reveals a deeper structural failure mode: **syntactic hyper-compression**.

**Clark, Martin, and Mahowald (2026)** demonstrate this phenomenon in [*Why is AI-generated language so hard to understand?*](https://arxiv.org/abs/2610.29162). Reinforcement learning with verifiable rewards (RLVR) under length penalties drives models toward extreme compression. This optimization produces an alien dialect—informally known as **"Claudish"**—that conflicts directly with human cognitive architecture.

`human-readable` is a dual deliverable designed to solve this problem:
1. **An Agent Skill:** Guides coding agents (Claude Code, Cursor, Antigravity, OpenCode, Codex, Copilot) to generate natural, low-cognitive-load prose.
2. **A Deterministic Verifier:** A zero-dependency, ultra-fast ($<10\text{ms}$) linter that checks technical text and enforces the cognitive rules discovered in empirical research.

## The Cognitive Science: Why AI Text Exhausts the Reader

Human natural language evolved under dual constraints: ease of production for the speaker and ease of comprehension for the listener. Under the principle of **Uniform Information Density (UID)** (Levy & Jaeger 2007), humans insert optional grammatical markers to keep the rate of information transfer smooth and prevent cognitive overload.

In contrast, frontier LLMs undergo optimization where correctness is decoupled from human communication. When models operate under context limits and token penalties, they systematically adopt structures that degrade human comprehension:

```
+---------------------------------------------------------------------------------------------------+
|                                  THE COGNITIVE MISALIGNMENT                                       |
+------------------------------------+----------------------------------+---------------------------+
| Human Biological Constraint        | Frontier LLM Architecture        | Resulting AI Pathology    |
+------------------------------------+----------------------------------+---------------------------+
| Lossy, distance-sensitive memory   | Full bidirectional self-attention | Extended dependency spans |
| Incremental real-time parsing      | Zero memory decay over tokens    | Deep center embeddings    |
| Channel capacity bottlenecks (UID) | Reward tied to brevity & latency | Stripped function words   |
| Animacy & thematic expectations    | Metaphorical token compression   | P600 ERP brainwave spikes |
+------------------------------------+----------------------------------+---------------------------+
```

## The Six Psycholinguistic Rules

The `human-readable` engine audits text against the six structural properties that predict human processing difficulty in research:

### 1. Explicit Function Words (Retain Optional Relativizers)
* **The Failure Mode:** Models strip optional relativizers (`that`, `which`, `who`) to conserve tokens.
* **Cognitive Cost:** Omitting `that` creates temporary structural ambiguity, forcing human working memory to perform syntactic reanalysis.
* **Target:**
  - **Natural:** *"The bug that the team identified yesterday..."*
  - **Avoid:** `"The bug the team identified yesterday..."`
  - **Natural:** *"The engineer confirmed that the test passed."*
  - **Avoid:** `"The engineer confirmed the test passed."`

### 2. Unpack Stacked Compound Nouns
* **The Failure Mode:** Models compress concepts into chains of three or more consecutive nouns (`reader-patience budget`, `class-time shutdown requirement`).
* **Cognitive Cost:** Forces hierarchical bracketing decisions ($[A\ [B\ C]]$ versus $[[A\ B]\ C]$), causing measurable eye-fixation regressions (Cooper 1980, Staub et al. 2007).
* **Target:**
  - **Natural:** *"budget for reader patience"*
  - **Avoid:** `"reader-patience budget"`
  - **Natural:** *"requirement to shut down during class hours"*
  - **Avoid:** `"class-time shutdown requirement"`

### 3. Selectional Restriction & Agency Alignment
* **The Failure Mode:** Attributing animate agency, physical consumption, or psychological states to abstract code entities (`the check forgot bytes`, `the script swallows the error`, `chaos expects you`).
* **Cognitive Cost:** Triggers an electrophysiological **P600 ERP brainwave** response, signaling cognitive repair and confusion (Kim & Osterhout 2005, Kuperberg 2007).
* **Target:**
  - **Natural:** *"The developer omitted the byte check"* or *"The check does not cover bytes."*
  - **Avoid:** `"The check forgot bytes."`
  - **Natural:** *"The script catches and suppresses the exception."*
  - **Avoid:** `"The script swallows the exception."`

### 4. Established Verbal Phrases Over Ad-Hoc Denominals
* **The Failure Mode:** Coercing prototypical nouns into verbs (`calendar it`, `footnote it`, `dotfolder`).
* **Cognitive Cost:** Forces late-stage syntactic re-parsing to resolve part-of-speech conversion (Thierry et al. 2008).
* **Target:**
  - **Natural:** *"Add a footnote to the explanation."*
  - **Avoid:** `"Footnote it."`
  - **Natural:** *"Schedule the meeting on the calendar."*
  - **Avoid:** `"Calendar it."`

### 5. Dependency Proximity & Sentence Breathing Room
* **The Failure Mode:** Distant separation between syntactic heads and dependents, and sentence sprawl exceeding thirty words without punctuation.
* **Cognitive Cost:** Human working memory decays across intervening referents, triggering cognitive exhaustion under **Dependency Locality Theory (DLT)** (Gibson 1998, 2000).
* **Target:** Keep subjects and verbs proximal. Split sprawling sentences into clean, distinct units.

### 6. Elimination of Claudish Cliches
* **The Failure Mode:** High-surprisal, low-frequency formulaic boilerplate (`quietly eating its own`, `delve into`, `rich tapestry`, `serves as a testament to`, `verified red`).
* **Cognitive Cost:** Produces reader fatigue, lowers information density, and signals unedited machine output.
* **Target:** State findings and actions directly without rhetorical padding.

## Quickstart & Installation

Install the skill into your development environment through any of the following methods:

### Option 1: Universal Agent Skills CLI (`npx skills`)
Install into seventy or more coding agents (Claude Code, Cursor, Antigravity, OpenCode, Codex, Copilot) via [skills.sh](https://skills.sh):

```bash
# Install to the current repository
npx skills add amanverma-765/human-readable --skill human-readable

# Or install globally across all configured agents
npx skills add -g amanverma-765/human-readable --skill human-readable
```

### Option 2: Direct Single-Command via `npx`
Run directly from GitHub without cloning:

```bash
# Install into the current project (.agents/skills/ and skills/)
npx github:amanverma-765/human-readable install

# Or install globally across all detected agents on your system
npx github:amanverma-765/human-readable install --global
```

### Option 3: Python Package Installation
For local development, CI pipelines, or pre-commit hooks:

```bash
git clone https://github.com/amanverma-765/human-readable.git
cd human-readable
pip install -e .
```

## CLI Usage

`human-readable` runs instantly with zero external dependencies, making it suitable for pre-commit hooks and automated test suites.

### Auditing Text Directly

```bash
python3 -m readable -s "Your instinct is right; the convoluted sentence you are currently reading is quietly eating its own reader-patience budget — footnote it."
```

#### Diagnostic Output:
```text
Line 1:25 [selectional-restriction] (ERROR)
  "the convoluted sentence you are currently reading is quietly eating"
  ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  Why: Selectional restriction violation: Inanimate subject 'sentence' paired with animate agency verb 'eating'
  Cognitive Cost: Triggers a P600 ERP brainwave response indicating syntactic reanalysis and semantic repair (Kim & Osterhout 2005, Kuperberg 2007).
  Suggestion: Rephrase to attribute action to human authors (e.g. 'The developer omitted...'), or use a functional predicate (e.g. 'The sentence does not handle...', 'fails to...', 'is designed to...')

Line 1:40 [reduced-relative] (WARNING)
  "sentence you are"
  ^^^^^^^^^^^^^^^^
  Why: Reduced object relative clause omitting 'that': 'sentence you are'
  Cognitive Cost: Reduced ORCs create non-canonical order without overt marking, depleting human working memory and triggering garden-path regressions (Staub 2010).
  Suggestion: Insert overt relativizer 'that': 'sentence that you are'

Line 1:78 [claudish-jargon] (WARNING)
  "quietly eating its own"
  ^^^^^^^^^^^^^^^^^^^^^^
  Why: Overused AI dialect marker / cliche: 'quietly eating its own'
  Cognitive Cost: High surprisal and low communicative value; creates reader fatigue and signals artificial dialect (Juzek & Ward 2025, Clark et al. 2026).
  Suggestion: Overused AI metaphor violating selectional restrictions and natural register. Rewrite using direct, plain, natural phrasing.

Line 1:101 [stacked-nouns] (WARNING)
  "reader-patience budget"
  ^^^^^^^^^^^^^^^^^^^^^^
  Why: Stacked noun compound (3 nouns modifying each other): 'reader-patience budget'
  Cognitive Cost: Forces hierarchical bracketing ambiguity ([A [B C]] vs [[A B] C]) and causes eye-fixation reading regressions (Cooper 1980, Staub et al. 2007).
  Suggestion: Unpack the compound into a prepositional phrase, e.g., 'budget for/of reader-patience'

Line 1:126 [denominal-verb] (WARNING)
  "footnote it"
  ^^^^^^^^^^^
  Why: Ad-hoc denominal verb conversion: 'footnote it'
  Cognitive Cost: Forces syntactic category disambiguation, triggering late-stage syntactic re-parsing (Thierry et al. 2008, Federmeier et al. 2000).
  Suggestion: Replace with standard verbal phrase: 'add a footnote to'

Readable Summary: 5 violation(s) found (1 error(s), 4 warning(s)).
```

### Auditing Documentation and Markdown

```bash

# Verify an entire directory recursively
python3 -m readable docs/

# Verify from standard input
git diff main | python3 -m readable -
```

```bash
python3 -m readable --strict docs/
```

```bash
python3 -m readable --format github docs/
```

## Agent Skill Integration

When installed in an agent workspace, the `human-readable` skill guides the agent during drafting and enforces a self-verification loop.

```
+-----------------------------------------------------------------------------+
|                          AGENT EXECUTION WORKFLOW                           |
+-----------------------------------------------------------------------------+
| 1. Model drafts technical explanation, PR summary, or documentation.        |
| 2. Model applies positive syntactic rules (explicit that, unpacked nouns).  |
| 3. Model executes: `python3 -m readable --strict <draft>`                   |
| 4. If diagnostics appear, model applies suggested rewrites.                 |
| 5. Clean output presented to human engineer with zero cognitive debt.       |
+-----------------------------------------------------------------------------+
```

### Supported Environments
- **Claude Code:** Discovered via `.claude-plugin/plugin.json` or `.claude/skills/`.
- **Antigravity / Gemini CLI:** Discovered via `.agents/skills/human-readable/SKILL.md`.
- **Cursor / OpenCode:** Discovered via `.cursor/skills/` or `skills/human-readable/`.
- **Codex / Copilot:** Discovered via standard project root skill directories.
